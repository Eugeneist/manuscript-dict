# stress-extra — доповнення до `stress/`

Цей каталог доповнює словник наголосів у `stress/` і не змінює його. Редактор поезії Манускрипта накладає його поверх `stress/`: якщо слово є тут, береться запис звідси.

| Файл | Що це |
|---|---|
| `{літера}.json` | `{ "слово": [наголоси] }` за першою літерою слова; індекс наголосу рахується серед голосних |
| `_guess.json` | модель «за закінченням» для слів, яких немає в жодному словнику |
| `_meta.json` | версія, лічильники, джерела |

## Навіщо

1. Шарди `stress/` зберігали лише перший запис слова. Через це:
   - омографи губили другий наголос (пора́ / по́ра, реве́ / ре́ве);
   - деякі звичайні слова отримали наголос однойменної власної назви (мені → «Ме́ні», або → «А́бо»).

   Тут для 34 тис. слів подано всі варіанти, записані з малої літери.
2. У джерелі немає частини займенників і числівників: його́, її́, ньо́го, йому́, ни́ми, кого́, п'яти́ тощо. Їх додано вручну зі списку `tools/stress-extra-closed.txt`.
3. **СУМ-11** додає:
   - 1 389 лем, яких немає в джерелі (старий правопис: агрус, барокко);
   - 790 варіантних наголосів.
4. **Словник Грінченка** додає 5,5 тис. слів XIX ст., яких ніде немає.
5. Модель «за закінченням» обирає наголос для слів, яких немає в жодному словнику.
   - Її перевірили на 10 % словника, яких вона не бачила під час навчання.
   - Перший кандидат правильний у 80 % випадків, правильний серед двох кандидатів — у 89–93 %.
   - Стара евристика «передостанній склад» вгадувала лише в 35 % випадків.

## Як перегенерувати

```
python tools/build_stress_extra.py --sum ukr-ukr_SUM-11_or_1.json --grinchenko ua-ru-hrinchenko.json
```

Обидва JSON беруться з релізів `github.com/bakustarver/ukr-dictionaries-list-opensource`, формат DiktJson. Скрипт працює на Python 3.9+ і потребує лише стандартної бібліотеки.

## Джерела й атрибуція

- lang-uk/ukrainian-word-stress-dictionary — `stress_original.txt` у цьому репозиторії; дані «Словників України» УМІФ НАН України.
- Словник української мови в 11 т. (АН УРСР, 1970–1980) — суспільне надбання.
- Б. Грінченко, Словарь української мови (1907–1909) — суспільне надбання.
- Оцифрування СУМ-11 і Грінченка — bakustarver/ukr-dictionaries-list-opensource.
- З усіх джерел узято лише факти «слово — місце наголосу».
