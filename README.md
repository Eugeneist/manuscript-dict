# Ukrainian Stress Dictionary Shards

Цей репозиторій містить оброблену версію словника наголосів **ukrainian-word-stress-dictionary**.

## Джерело

Вихідні дані взято з репозиторію **ukrainian-word-stress-dictionary**:

https://github.com/lang-uk/ukrainian-word-stress-dictionary

Згідно з описом оригінального проєкту, словник сформовано на основі **«Словників України» Українського мовно-інформаційного фонду НАН України**.

Початковий словник містить приблизно **2,9 мільйона словоформ і словосполук української мови** з позначеними наголосами.

## Призначення

Цей репозиторій не змінює мовні дані словника.

Його метою є підготовка даних для ефективного використання на платформі **Манускрипт** шляхом розбиття словника на невеликі шард-файли та створення структур, оптимізованих для швидкого завантаження.

Згенеровані дані використовуються у двох незалежних модулях.

### `stress/`

Шардований словник наголосів для редактора поезії Манускрипта.

### `rhymes/`

Перетворені та оптимізовані дані для генератора рим Манускрипта.

## Обробка

Під час генерації:

* зчитується оригінальний словник;
* записи розбиваються на шард-файли;
* створюються структури даних для швидкого пошуку та завантаження;
* зберігається інформація про наголоси.

Мовні дані не змінюються — змінюється лише спосіб їх організації та зберігання.

## Атрибуція

Цей репозиторій містить похідні дані, сформовані на основі словника **ukrainian-word-stress-dictionary**, який, згідно з його описом, базується на **«Словниках України» Українського мовно-інформаційного фонду НАН України**.

Оригінальний репозиторій:
https://github.com/lang-uk/ukrainian-word-stress-dictionary

## Примітка

На момент створення цього репозиторію оригінальний проєкт не містив окремого файлу ліцензії. Якщо умови використання оригінального словника будуть уточнені або змінені його автором, цей репозиторій буде приведено у відповідність до них.
